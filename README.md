## Featured projects

**[INSPIRE by OpenFountain](https://inspire-platform.vercel.app)** · Next.js, Flutter, Supabase, Cloudflare R2, FFmpeg
An offline-first audio Bible for low-data Africa. A pipeline re-encodes open-licensed audio to 32 kbps mono (about 55% smaller, roughly 0.8 MB per chapter) and serves it from edge storage with zero egress cost. Tested on a real 2G network in Lagos.

**[wedding-backend](https://github.com/Elvinique/wedding-backend)** · Go, Fiber, PostgreSQL (Supabase)
REST API for a wedding invitation app: RSVPs with duplicate prevention, unique QR codes per guest with entrance verification, guestbook, email confirmations, and rate limiting. Layered handlers / services / repository structure, Dockerised, with a live API.

**[Community-Safety-Alert-App-Backend](https://github.com/Elvinique/Community-Safety-Alert-App-Backend)** · Python, Flask, PostgreSQL
Team project (five contributors): backend for a real-time safety reporting platform for Nigerian communities, with CI through GitHub Actions.

**E-wallet & bill payments platform** · Go, Next.js, React Native, PostgreSQL, Redis *(in progress)*
A Go transaction engine with integer (kobo) money values, row-level locking against double-debits, and idempotency keys for safe retries.
